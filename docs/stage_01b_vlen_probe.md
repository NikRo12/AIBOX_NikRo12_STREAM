# Этап 1b. Эмпирическая проверка VLEN на X100 и A100

## Что сделано
Написана мини-программа с инлайн-ассемблерными вставками (RISC-V CSR
`vlenb` + инструкция `vsetvli` с rs1=x0 для чтения VLMAX), которая
эмпирически измеряет реальную длину векторного регистра на каждом
типе ядра AIBOX-K3, вместо того чтобы полагаться только на документацию
ISA-профилей (zve32f/zve64d).

## Код
`tools/vlen_probe/vlen_probe.c` — читает CSR vlenb и VLMAX для
SEW=8/16/32/64 при LMUL=1 и LMUL=8.

## Сборка
    gcc -O2 -march=rv64gcv -o vlen_probe vlen_probe.c

## Результаты (эмпирические, измерено напрямую на железе)

| Параметр                  | X100 (hart 0) | A100 (hart 8) |
|---------------------------|---------------|---------------|
| VLENB (CSR)                | 32 байта      | 128 байт      |
| VLEN (derived)              | 256 бит       | 1024 бит      |
| VLMAX fp32 (SEW=32,LMUL=1)  | 8 элементов   | 32 элемента   |
| VLMAX fp64 (SEW=64,LMUL=1)  | 4 элемента    | 16 элементов  |
| VLMAX fp32 (LMUL=8)         | 64 элемента   | 256 элементов |
| VLMAX fp64 (LMUL=8)         | 32 элемента   | 128 элементов |

Результат **полностью подтверждает** теоретический расчёт из паспорта
платы (VLEN 256/1024 бит, взятые из документации по zve32f/zve64d
профилям) — теперь это не предположение, а измеренный факт.
